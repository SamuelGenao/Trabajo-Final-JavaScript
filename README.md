# PixelFinder

## Descripción

PixelFinder es una aplicación web desarrollada con HTML, CSS y JavaScript que permite buscar imágenes mediante la API de Pexels. La aplicación ofrece una interfaz intuitiva para realizar búsquedas, filtrar resultados y guardar imágenes favoritas utilizando LocalStorage.

## Funcionalidades

- Buscar imágenes por palabra clave.
- Filtrar resultados por orientación.
- Seleccionar la cantidad de imágenes a mostrar.
- Visualizar fotografías en alta resolución.
- Guardar y eliminar imágenes favoritas.
- Almacenar favoritos mediante LocalStorage.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- API de Pexels
